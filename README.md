# Replication of Holden (2016) - "Buy the Book"

##  Project Overview
This repository contains the Stata code and non-sensitive output file for a replication of Kristian L. Holden's 2016  paper, "Buy the Book". The project focuses on applying causal inference techniques to replicate the core findings of the original study.

Holden, Kristian L. 2016. "Buy the Book? Evidence on the Effect of Textbook Funding on School-Level Achievement." American Economic Journal: Applied Economics 8 (4): 100–127.

## Methodology
The analysis employs a **Sharp Regression Discontinuity Design (RDD)**. The included Stata script demonstrate the programming of the mathematical expressions, the alignment of data bins at the defined cut-off, and the calculation of average performance metrics to estimate the causal treatment effects.
